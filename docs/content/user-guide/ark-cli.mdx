# Using the ARK CLI

## Installation

```bash
npm install -g @agents-at-scale/ark
```

## Basic Usage

```bash
# Enable tab completion (add to ~/.bashrc or ~/.zshrc)
eval "$(ark completion bash)"      # For bash
eval "$(ark completion zsh)"       # For zsh

# Install ark - or install and wait for it to be ready.
ark install
ark install -y --wait-for-ready=5m  # chooses 'yes' for each option

# Show ark status.
ark status

# Start interactive chat
ark chat

# Chat with a specific target
ark chat agent/math

# Show current config.
ark config

# Uninstall ark.
ark uninstall
```

Then query any agent:

```
> @weather What's the weather today?
> @math Calculate 15 * 23
```

That's it! The CLI maintains conversation context and lets you interact with any deployed ARK agents.

## Local Development

```bash
# Navigate to the CLI source
cd tools/ark-cli

# Create global symlink
npm link --force

# Run directly or with live reload
ark         # Run the CLI
npm run dev # Or run with live reload
```

Changes to the source code will instantly reflect when you run `ark` commands.

## Queries Management

### Query a Model/Agent

To query a model/agent from ARK CLI is as simple as running:

- `ark query model/model-name "What's the weather today?"`
- `ark query agent/agent-name "What can you do?"`

### Inspecting Queries

With `ark queries list` or `ark queries ls` it is possible to retrieve all the queries made.  

This command supports sorting results by internal properties.

E.g.:
```sh
# sort queries by creation time
ark queries list --sort-by metadata.creationTimestamp

# sort queries by creation time
ark queries list --sort-by metadata.name

# sort queries by creation status
ark queries list --sort-by status.phase
```

By specifying the `json` output format, user can retrieve the list of raw queries.

E.g.:
```sh
# get the raw queries output
ark queries list -o json
```

### Deleting Queries

ARK CLI can delete queries by name or deleting all queries if `--all` flag is specified.

E.g.:
```sh
# delete query by name
ark queries delete cli-query-1762513858659

# delete all queries
ark queries delete --all
```
