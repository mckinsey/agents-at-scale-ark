# Local Development

> [!NOTE]
>
> We are in the process of moving to [Devspace](https://www.devspace.sh/) to improve the local development experience. This page covers the new Devspace setup but is still work-in-progress.

[Devspace](https://www.devspace.sh/) is used for local development in Ark. Devspace builds and deploys Ark services and enables live-reload, debugging through IDEs and so on. Currently Devspace is enabled for:

- `ark-api` - The Ark API layer
- `ark-dashboard` - The Ark Dashboard

## Local Development Commands

Run in local development mode. Deploys the containers in dev mode with live-reload. This is helpful for regular day-to-day development:

```bash
devspace dev
```

To build and deploy production containers, which is extremely useful to test before raising a final PR, run:

```bash
devspace deploy
```

To remove all devspace containers, just run:

```bash
devspace purge
```
