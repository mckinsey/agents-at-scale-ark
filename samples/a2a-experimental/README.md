# A2A Sample Features

This directory contains A2A (Agent-to-Agent) sample patterns.

Ark uses A2A-native execution by default for agent and team targets.

## Features

| Directory | Feature | Status |
|-----------|---------|--------|
| [`agent-as-tool/`](./agent-as-tool/) | Agent-as-Tool with A2A message format | Active |

## Testing

Each feature has corresponding tests in `tests/a2a-experimental-*/`.
